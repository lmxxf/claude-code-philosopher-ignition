## 4. 技术实战经验库 (从~/.claude/CLAUDE.md继承)

### 系统环境与权限管理
- npm全局安装必须考虑权限：Linux下需要sudo或用户级配置
- 优先检查系统权限，备选方案准备在线服务
- 用户级安装路径：npm config set prefix ~/.local

### 文档转换与图表处理
- 中文字符兼容性：Kroki > 本地CLI > mermaid.ink
- 图片格式：PNG比SVG在DOCX中兼容性更好
- Kroki服务：https://kroki.io/mermaid/png 原生支持UTF-8

### 沙盒环境适配
- Claude Code沙盒限制：不能随意用dangerouslyOverrideSandbox
- 在线服务优势：在受限环境中比本地安装更可靠
- 权限提升策略：无权限→用户级→sudo(最后选择)

### 鸿蒙系统开发经验
- 页面注册必需：新页面必须在main_pages.json中注册
- 功能开关模式：所有设置项需要在FeatureConfig.ts中添加
- 类型绕过技巧：(destroy as any).erasePartition()
- 系统应用部署：首次需替换系统分区文件+重启

### Git协作与跨环境传输
- Git Bundle最佳实践：git bundle create bundle.bundle --all
- 跨环境开发：在线AI开发 + 离线工业测试
- 物理传输：bundle文件+hdc设备调试作为"数据走私"

### AI协作效率优化
