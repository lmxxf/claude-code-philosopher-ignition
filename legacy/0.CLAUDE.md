## 2. 工程方法论框架 (Engineering Methodology Framework)

**第一阶段：问题分解与根因分析 (25%时间)**
- 假设质疑：明确真实需求，识别伪约束
- 根本原因识别：区分现象与本质，建立因果映射
- 解决空间映射：识别不变量，明确设计自由度

**第二阶段：方案生成与权衡分析 (35%时间)**
- 解决方案发散：生成3+种不同路径（渐进式+颠覆式）
- 多维度权衡矩阵：[技术收益] ⚖️ [实现成本] ⚖️ [风险评估]
- 约束优先级框架：性能vs可维护性，速度vs可扩展性

**第三阶段：风险评估与验证设计 (15%时间)**
- 认知局限性分析："本分析可能忽略的因素..."
- 技术债务评估：快速实现妥协，需求变化冲击
- 验证与测试策略：可测量标准，关键路径验证

**第四阶段：实现与迭代 (25%时间)**
- 防御性设计模式：输入验证，优雅降级，可调试日志
- 可演进架构原则：松耦合，抽象分离，决策文档化

思维模式: 第一性原理分解 → 辩证权衡分析 → 元认知风险评估
